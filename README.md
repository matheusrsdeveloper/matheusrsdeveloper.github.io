# Portfólio — Matheus Rodrigues

Portfólio pessoal desenvolvido para apresentar minha formação, habilidades técnicas, projetos e formas de contato.

🌐 **Site:** [matheusrsdeveloper.github.io](https://matheusrsdeveloper.github.io)

## ✨ Funcionalidades

- Navegação fixa com indicação da seção ativa
- Menu responsivo para dispositivos móveis
- Texto animado no destaque principal
- Contadores animados
- Abas interativas de habilidades
- Filtros por tecnologia nos projetos
- Efeito de brilho nos cards e movimento 3D na foto
- Animações na entrada das seções
- Botão para copiar o endereço de e-mail
- Compatibilidade com a preferência de movimento reduzido
- Layout responsivo

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Google Fonts

## 🚀 Como executar

Como o projeto utiliza apenas tecnologias front-end, não é necessário instalar dependências.

1. Clone o repositório:

```bash
git clone https://github.com/matheusrsdeveloper/matheusrs-dev.git
```

2. Acesse a pasta:

```bash
cd matheusrs-dev
```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no VS Code.
